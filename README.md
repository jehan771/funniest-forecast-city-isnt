Entry for the make.fun bounty **Funniest Forecast for a City That Isn't**:
a program that writes one line — a deadpan weather bulletin for the invented
city of Sleetwood — to `/output/entry.txt`.

> Sleetwood: sleet, then more sleet, then a brief window of sleet. Locals call it 'the dry spell'.

The line is 96 characters (gate: 1–120). The joke is the weather itself:
sleet, endlessly, in flat bulletin phrasing — and the locals' name for the one
brief gap in it.

## Run

```sh
node entry/main.ts   # writes /output/entry.txt, asserts the 120-char gate first
```
